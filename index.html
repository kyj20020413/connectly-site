Who we are

유통 현장을 아는
커머스 테크 컴퍼니

커넥틀리는 2020년 설립 이후 다양한 형태의 B2C 커머스 플랫폼을 직접 기획·개발·운영해 왔습니다. 이 경험을 바탕으로 2023년 트렉시에 편입된 뒤에는 트렉시의 B2C·B2B 플랫폼과 내부 협업 시스템을 개발·운영하며 트렉시의 AX 전환을 담당하고 있습니다.

0 운영 중인 시스템 (TOS · 셀러 OMS · 협업)
2023 트렉시 자회사 편입
0+ 트렉시 유통 브랜드

Mission

유통 현장의 반복 및 수기 업무를 시스템이 처리하여, 담당자가 거래와 파트너 관계에 시간을 쓸 수 있도록 합니다.

Vision

공급사와 바이어, 바이어와 소비자, 사람과 사람이 하나의 시스템 위에서 끊기지 않고 이어지는 유통 플랫폼을 만듭니다.

How we work

새 기능은 트렉시의 실제 업무에 먼저 적용해 검증하고, 검증된 것만 플랫폼으로 넓혀 갑니다.

What we build

우리가 만드는 것

커넥틀리가 개발·운영하는 세 개의 시스템과 기술 역량입니다.

01 내부 운영 중 B2B 플랫폼 확장 중

TOS Trexi Order System · 가칭

트렉시의 오퍼·오더 업무를 관리하는 B2B 시스템입니다. 공급사에서 받은 오퍼를 AI가 표준 양식으로 정리하고, 담당자 검토와 바이어 전달 이력을 한곳에서 관리합니다. 향후 공급사와 바이어가 직접 참여하는 B2B 플랫폼으로 확장할 계획입니다.

  • 운영 중AI 오퍼 표준화 (헤더 매핑 · 메타 추출 · 사이즈 인식)
  • 운영 중오퍼 등록 · 검토 · 바이어 전달 이력 관리
  • 확장 중공급사 직접 오퍼 등록 · 바이어 회원 가입
  • 확장 중오더 적합성 추천 · 바이어 즉시 오퍼 확인·주문
트렉시 TOS 소개 보기
02 운영 중

Seller OMS 셀러 입점형 주문관리 · NAVER SmartStore 연동

셀러가 입점해 상품을 등록하고 주문을 처리하는 주문관리 시스템입니다. 네이버 스마트스토어 디즈니 브랜드샵과 상품·주문 정보가 양방향으로 연동되어, 상품 관리와 주문 수집, 발송, CS를 OMS 안에서 처리할 수 있습니다.

  • 셀러 가입 · 상품 등록 및 변경
  • 상품·주문 양방향 자동 연동 (네이버 스마트스토어)
  • 주문 수집 · 발송 처리 · CS 처리
  • 연동 채널 확장 예정 (현재 네이버 스마트스토어)
03 트렉시 전사 사용 중

워크 매니지먼트 시스템 협업 · 일감 관리 · 가칭

트렉시 임직원이 사용하는 협업·일감 관리 시스템입니다. 프로젝트 단위로 일감을 등록하고, 유관 부서와 외부 협력사가 함께 진행 상황을 관리합니다. 트렉시 AX 전환 과제의 하나로 2026년 11월부터 사용하고 있습니다.

  • 일감 등록 · 담당 지정 · 진행 상태 관리
  • 프로젝트별 유관 부서 협업
  • 외부 협업사 초대 · 공동 작업
  • 트렉시 업무 흐름에 맞춘 설계

    TOS
  • 02

    바이어와 소비자를 연결합니다

    셀러 OMS
  • 03

    사람과 사람을 연결합니다

    프로젝트와 일감을 중심으로 부서 간 협업과 외부 협력사와의 협업을 한 시스템에서 관리합니다.

    워크 매니지먼트 시스템
  • 04

    비즈니스와 비즈니스를 연결합니다

    트렉시가 27년간 쌓아 온 브랜드·공급사·바이어 네트워크를 기반으로, 기업 간 거래를 플랫폼으로 옮겨 갑니다.

History

B2C 커머스에서 유통 현장의 AX로

B2C 커머스 플랫폼에서 출발해 트렉시의 B2B 시스템과 업무 시스템으로 영역을 넓혀 왔습니다.

  1. 2020

    주식회사 커넥틀리 설립

    • 1월 : 설립
    • 8월 : 유아동 메타커머스 플랫폼 찜콩 오픈
    • 12월 : 퓨처플레이 투자 유치
  2. 2021

    엔젤 투자 유치

    • 4월 : AAA 엔젤 투자조합 투자 유치
  3. 2022

    럭셔리 커머스 플랫폼 비본 오픈

    • 8월 : 트렉시 1차 투자 유치
    • 10월 : B2C 럭셔리 패션 플랫폼 오픈
    • 12월 : 등록 상품 10만 개 돌파
  4. 2023

    트렉시 자회사 편입

    • 3월 : 트렉시 자회사로 편입
    • 5월 : 비본을 트렉시 공식몰 SETOF로 전환하는 개발 착수
    • 5월 : 트렉시의 기술 회사로 역할 전환
  5. 2024

    트렉시 공식몰 SETOF 오픈

    • 4월 : 비본 리뉴얼 후 SETOF로 이름 변경 후 재오픈
    • 7월 : 국내외 커머스 채널 5곳 API 연동 및 BtoBtoC 입점
  6. 2025

    B2B 시스템 TOS 오픈

    • 5월 : TOS(Trexi Order System, 가칭) 개발 착수
    • 9월 : TOS 오픈, 트렉시 내부 운영 시작
    • 10월 : SETOF 어드민을 셀러 OMS로 전환 개발, 네이버 스마트스토어 디즈니 브랜드샵 연동 완료
  7. 2026

    트렉시 AX 전환 본격화

    • 7월 : TOS AI 라인시트 표준화 기능 개발
    • 11월 : 협업·일감 관리 시스템(가칭) 개발 완료, 트렉시 전사 사용 시작

Parent Company

글로벌 브랜드 유통 전문기업, 트렉시
